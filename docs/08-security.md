# Security Architecture & Threat Model

SafeDeal operates on a **trust-minimized custody boundary**: backend API, database, RPC endpoints, browser sessions, and the Chrome Extension are never permitted custody over user funds. Smart contract controls enforce solvency on Avalanche; Web2.5 security controls protect authentication integrity, terms verification, dispute evidence confidentiality, and availability.

## 1. On-Chain Threat Controls (`SafeDealEscrow.sol`)

- **Zero Admin Custody / Upgrade Risk**: Contract is non-upgradeable with no `owner`, `pause()`, or `sweep()` backdoor.
- **Pull-Payment Reentrancy & DoS Isolation**: `withdraw()` applies OpenZeppelin `ReentrancyGuard` and zero-before-transfer `Checks-Effects-Interactions`. Reverting receivers only affect their own `withdraw()`, never countersigning payouts.
- **Role Isolation**: Contract enforces `seller != arbiter`, `buyer != seller`, `buyer != arbiter`, and `arbiter != address(0)`.
- **2-of-3 Consensus & Sum Invariant**: `submitResolutionVote` requires 2-of-3 matching votes across `[buyer, seller, arbiter]` and checks `buyerAmount <= trade.amount && sellerAmount == trade.amount - buyerAmount`, preventing unilateral arbiter seizure, overpayment, or leftover dust lockup (`arbiter` receives `0`). After 14 days (`DISPUTE_TIMEOUT`), `resolveDisputeByTimeout` enforces a deterministic 50/50 split (`buyerAmount = trade.amount / 2`, `sellerAmount = trade.amount - buyerAmount`) so funds cannot be held hostage.
- **Direct Transfer Prevention**: `receive()` and `fallback()` revert immediately (`DirectTransfersNotAllowed`).

## 2. Backend & Web API Security Controls

| Threat Vector | Implemented Control | Primary Implementation |
|---|---|---|
| **Wallet Impersonation & Replay** | EIP-4361 (SIWE) message parsing checks domain, URI, chainId, expiry, and secp256k1 public-key recovery via `k256` (canonical and normalized `v` values). Challenges expire after `NONCE_TTL_SECONDS`, are consumed atomically once in SQL (`AuthNonceRepository::consume_once`), and expired rows are swept by `CleanupOrphanDraftsUseCase` (`AuthNonceRepository::delete_expired_before`). | `SiweAuthService`, `SiweMessageParser`, `K256SignatureVerifier` |
| **Dual-Mode Session Security (XSS & Cross-Origin 3PCD Resilience)** | Same-site requests use a signed HS256 JWT in an `HttpOnly` cookie (`safedeal_session`) paired with Double-Submit CSRF (`safedeal_csrf` cookie + `X-CSRF-Token` header). For cross-origin deployments where third-party cookies are blocked between Firebase Hosting (`avalanche-9b099.web.app`) and Railway (`safedeal-production.up.railway.app`), `/api/v1/auth/verify` also supports `Authorization: Bearer <token>` authentication (including authenticated Blob evidence downloads). | `JwtSessionService`, `csrf_protection_middleware`, `downloadAuthenticatedAttachment` |
| **Cross-Site Request Forgery (CSRF)** | `csrf_protection_middleware` enforces equality between `safedeal_csrf` cookie and `X-CSRF-Token` header on cookie-authenticated state-changing routes (`POST`, `PUT`, `PATCH`, `DELETE`). Exempt public pre-session auth initiation routes are guarded by SIWE wallet signatures & peer-IP rate limiting. | `csrf_protection_middleware` (`crates/infrastructure/src/security.rs`) |
| **Auth Challenge/Verify Abuse** | `AuthRateLimitState` enforces sliding-window IP throttling on `/api/v1/auth/nonce` and `/api/v1/auth/verify` (`429 RATE_LIMITED`). Client keys use Axum `ConnectInfo<SocketAddr>` peer IP directly by default (`AUTH_TRUST_PROXY_HEADERS=false`, ignoring raw spoofable `X-Forwarded-For` headers unless explicitly behind a trusted proxy) with bounded memory eviction of expired windows. | `AuthRateLimitState`, `ConnectInfo<SocketAddr>` |
| **Weak Production Secrets / Misconfig** | `AppConfig::validate` (`validate_common_and_production` / `validate_production_configuration`) fails startup in `prod` or `staging` profiles if `JWT_SECRET` contains placeholder words (`replace-with`, `placeholder`, `changeme`, `change-me`, `dev-only`, `test-only`, `example`), is `< 32` chars, `COOKIE_SECURE` is `false`, `CORS_ALLOWED_ORIGINS` contains `*` or loopback addresses, or `SIWE_DOMAIN`/`SIWE_URI`/`AVALANCHE_RPC_URL` use `localhost` / `127.0.0.1` / `[::1]`. | `AppConfig::validate` (`crates/infrastructure/src/config.rs`) |
| **Off-Chain Terms Substitution** | Frontend (`canonical-terms.ts`), Chrome Extension (`extension/shared/canonical-terms.js`), and backend (`CanonicalTermsHasher` in `canonical_terms.rs`) independently generate RFC 8785 Canonical JSON SHA-256 `termsHash`; `BindDealTransactionUseCase` & `SyncDealUseCase` verify equality against on-chain `TradeCreated` events and `getTrade` state. | `CanonicalTermsHasher`, `BindDealTransactionUseCase`, `SyncDealUseCase` |
| **DB Pool Exhaustion Under Slow RPC** | External Alloy RPC calls always execute outside database transactions (`UnitOfWork::in_tx` encloses brief PostgreSQL reads/writes only). | `BindDealTransactionUseCase`, `SyncDealUseCase`, `ArbitrationUseCase`, `BlockchainEventIndexerService` |
| **Malicious File Upload, Disk Tampering & Path Traversal** | `LocalEvidenceStorageAdapter` (and `S3EvidenceStorage`) enforces declared MIME allowlist (`image/png`, `image/jpeg`, `application/pdf`, `text/plain`), **magic-byte signature inspection** (`89 50 4E 47 0D 0A 1A 0A`, `FF D8 FF`, `%PDF-`, UTF-8 non-null/non-blank), strict size bounds, UUID storage filenames, canonical path containment, and **SHA-256 byte integrity verification (`evidence.verify_bytes_integrity`) on both upload and download**. | `LocalEvidenceStorageAdapter`, `DisputeUseCase::prepare_evidence_download` |
| **XSS / Sniffing via Evidence Downloads** | Downloads validate caller participation/arbiter ACL (`403` for non-actors), verify SHA-256 digest integrity, and send `Content-Disposition: attachment`, `X-Content-Type-Options: nosniff`, `Cache-Control: no-store`. | `routes::disputes`, `DisputeUseCase` |
| **Information Leakage & Secret Hygiene** | `ApiError` (`crates/presentation/src/error.rs`) maps domain/infrastructure errors into structured `ApiErrorPayload` + `correlationId` without internal stack traces. `.github/workflows/secrets-scan.yml` runs Gitleaks across commit history. | `ApiError`, `secrets-scan.yml` |
