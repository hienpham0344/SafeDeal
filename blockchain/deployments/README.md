# SafeDeal Contract Deployments

This directory stores versioned deployment manifests generated by deployment scripts (`script/Deploy.s.sol` and `scripts/deploy-local.sh`).

- `local-31337.json` — Local Anvil deployment metadata (generated locally, safe to regenerate).
- `fuji-43113.json` — Avalanche Fuji C-Chain testnet deployment manifest (populated after testnet deployment).

Never commit private keys or deployer secrets in deployment manifests.
